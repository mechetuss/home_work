Анализ ML дерева (Dayhoff+G+I, bootstrap=100)
ML дерево построено методом максимального правдоподобия с моделью Dayhoff+G+I, которая учитывает неравномерность замен между аминокислотами, гамма-распределение скоростей по сайтам и долю инвариантных позиций. Это наиболее статистически обоснованный из трёх методов.
На дереве видна чёткая кластеризация последовательностей -- несколько крупных клад с короткими внутренними ветвями, что говорит о высокой консервативности цитохрома c у позвоночных. Длинные внешние ветви у ряда таксонов могут указывать на ускоренную эволюцию в отдельных линиях.
LogL = -1252.72 -- значение правдоподобия дерева, используется для сравнения моделей (чем ближе к нулю, тем лучше).
